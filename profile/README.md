# SNEKPRTY

**Sound on. Everything else optional.**

We make games that run in your browser, and the music that goes with them. We're based in Chicago.

## Games

**[Floor Fifty](https://snekprty.com/floor-fifty)**: race three friends up a fifty-floor tower. First to the roof wins. Don't look down.
The code is in [FloorFifty-public](https://github.com/SNEKPRTY/FloorFifty-public) under Apache-2.0.

## Music

*Floor Fifty, the soundtrack*: 12 tracks from the game, out soon on Spotify, Apple Music and more.
